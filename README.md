# Ismail Bettoumi — UX/UI Designer

Independent portfolio, with its own content and CV. Live at https://yas1ne22.github.io/ismail-ux-ui-portfolio/

## Development

`npm ci` then `npm run dev`. `npm run build` produces `dist/`.

## Editing

Edit `src/data.js` for portfolio content. The CV is `public/cv.html`; regenerate `public/Ismail_Bettoumi_CV.pdf` from its print layout after CV changes. Keep the two versions consistent.

## Deployment

GitHub Actions builds and deploys main to GitHub Pages. Pages source: GitHub Actions. No custom domain is assigned. `vite.config.js` and static asset links use this repository's URL prefix.

## Content provenance

Initial content is based on Ismail's existing ismail-portfolio / ISMUX source and supplied CV. Employment titles and dates are preserved from his CV. UX/UI emphasizes documented Shopify and conversion work; social media emphasizes documented calendars, briefs, Meta campaigns and reporting. No Yassine employment history, personal imagery, or case studies are included. More detailed project screenshots and outcomes can be added after review.

## Design provenance

The shared visual foundation is adapted from the existing Bettoumi portfolio at the user's request; its original layout, font assets and window imagery were adapted from Mike Barton's mikes.cv. Boarding scanner uses Three.js.
